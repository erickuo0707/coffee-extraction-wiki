# Lint 紀錄 02 — 粉水比定義歧義與修正

- **執行日期：** 2026-11-15
- **檢查對象：** `checks/query-01-tds-ey.md` 及 `wiki/粉水比-濃度-萃取率.md`。
- **實際發現：** Query 問句寫「粉水比變大」，沒有指定是「水質量／咖啡粉質量」還是常見的「咖啡粉量：水量」表示法。兩者數值方向相反，可能讓讀者把 TDS 變化方向讀反。
- **最小修正：** Query 改用「水粉比（水質量 ÷ 咖啡粉質量）增加」並在回答明說，S03 的浸泡平衡條件下，較大的水／粉質量比對應較低 TDS；研究範圍內 EY 相對穩定。Wiki 比例頁補充必須把分子與分母寫出來。
- **重跑結果：** 再讀修正後的 Query 和比例頁，確認定義前後一致，TDS 方向與 S03 相符；相對連結及 S03/S04/S06 引用仍解析到相應來源檔。
- **依據：** [S03](../raw/S03-liang-immersion-model.md)。
